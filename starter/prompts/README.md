# Example prompts that work

A collection of prompts that have produced good results with Cursor + Claude/GPT. Steal them. Adapt them. Add your own as you find what works.

## Why save prompts?

A good prompt is a tiny program. It deserves the same care as code. The best engineers I know keep a personal "prompt library" the same way they keep a snippets folder.

## How these are structured

Each prompt is a markdown file with:
1. **Goal** — what task it's for
2. **Prompt** — the actual text to paste
3. **Why it works** — what to tweak when adapting

## In this folder
